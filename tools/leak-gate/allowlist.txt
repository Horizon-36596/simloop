# Exceptions to the rules in patterns.txt. One per line; blank lines and lines starting with # are
# ignored:
#
#   <rule-id>|<path>|<exact line text>
#
# The line text is compared after trimming leading and trailing spaces, so indentation does not matter
# but every other character does. If the line changes, the exception stops applying and the gate fails
# again, which is the point: someone has to look at the new line. There are deliberately no line
# numbers, so an edit elsewhere in the file does not break an exception.
#
# For a path or size rule, leave the text empty: <rule-id>|<path>|
#
# Every exception needs a comment saying why it is safe. The gate prints exceptions that matched
# nothing, so stale ones can be removed.
